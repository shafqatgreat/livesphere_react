````markdown
## 📌 About The Project

**LiveSphere_React** is a practical frontend project designed to:

- Build reusable components
- Understand React internals
- Practice state management
- Implement conditional rendering
- Observe Virtual DOM behavior
- Prepare for MERN Stack integration

This project emphasizes writing clean, scalable, and production-ready React code.

---

## 💻 Features Implemented

✔ Responsive Navbar  
✔ Login Modal Component  
✔ Props (Parent → Child communication)  
✔ State management with `useState`  
✔ Conditional Rendering  
✔ Short-circuit rendering  
✔ Loading Spinner logic  
✔ Virtual DOM behavior observation  

---

## 🧠 Concepts Covered

### 🔹 JSX
- Writing HTML-like syntax inside JavaScript
- Injecting dynamic values using `{ }`
- Using `className` instead of `class`

### 🔹 Props
- Passing `isOpen` and `onClose`
- Parent-to-child communication

### 🔹 State & Hooks
- Managing modal visibility
- Tracking `username`, `password`
- Handling loading state
- Using `useState` effectively

### 🔹 Conditional Rendering
- `if (!isOpen) return null`
- `{isLoading ? <Spinner /> : "Login"}`
- `isModalOpen && <Login />`

### 🔹 Virtual DOM
- Efficient UI updates
- Minimal DOM manipulation
- React reconciliation process

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash

```

### 2️⃣ Navigate to Project Folder

```bash
cd livesphere_react
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
````
