# 🚀 LiveSphere React

> A practical React project built for MERN Stack mastery.

---

## 📌 About

LiveSphere React is a hands-on frontend project focused on mastering core React concepts through real implementation.

---

## ✨ Features

- Responsive Navbar  
- Login Modal  
- Props Communication  
- useState Hook  
- Conditional Rendering  
- Virtual DOM behavior  

---

## 🧠 Concepts Covered

### JSX
Writing HTML inside JavaScript using React syntax.

### Props
Parent → Child communication.

### State & Hooks
Managing UI state using `useState`.

### Conditional Rendering
Dynamic UI updates using logical conditions.

---

- React.js  
- JavaScript (ES6+)  
- HTML5  
- CSS3
